🔑 Autorisation pour remplacer les vidéos

Pour remplacer une vidéo, ce téléphone ou cet ordinateur doit avoir une clé d'accès à ton dépôt GitHub « ecrans ». Elle reste enregistrée uniquement sur cet appareil. À faire une seule fois par appareil :

  1. Ouvre github.com/settings/personal-access-tokens/new (connecté à ton compte GitHub).
  2. Token name : « Écrans Moule & Smile ». Expiration : 1 an.
  3. Repository access : « Only select repositories » → choisis ecrans uniquement.
  4. Permissions → Repository permissions → Contents : « Read and write ».
  5. Clique Generate token, copie la clé (elle commence par github_pat_) et colle-la ici :

Sur les télés : ouvrez l'adresse courte de l'écran (ex. cevapizza11.github.io/ecrans/carte) dans le navigateur de la télé ou dans Fully Kiosk Browser. Sur un téléphone ou un ordinateur, touchez l'écran une fois pour passer en plein écran (touche F11 sur ordinateur).
Télécharger enregistre la vidéo actuelle sur cet appareil (clé USB, réseaux sociaux…).
Remplacer envoie une nouvelle vidéo (MP4, 1920×1080 conseillé, 40 Mo maximum). Les télés la prennent toutes seules en 5 à 10 minutes.
Les vidéos sont gardées en mémoire sur les télés : elles continuent si la wifi coupe.
